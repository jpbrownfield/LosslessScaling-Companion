GPU Selection ›

Auto-route follows the display containing the scaled window. If it moves to a display driven by another GPU, Companion unscales, updates that Lossless Scaling profile's preferred GPU and output display, restarts Lossless Scaling, restores target focus, and rescales.

RTX HDR is applied only to the LosslessScaling.exe NVIDIA application profile and takes effect the next time Lossless Scaling starts. Use it with SDR content and do not stack it with Special K or ReShade tone mapping.

Smart Auto Scale ›

When enabled, the companion disables Lossless Scaling's native Auto Scale to prevent conflicts, verifies and restores focus to the exact target window, loads that application's ReShade preset and managed custom DLLs into Lossless Scaling, then sends Lossless Scaling's own configured activation hotkey.

Only profiles with “Automatically scale this application” enabled are started automatically. The monitor option restores only windows minimized by the helper when scaling stops.

Process Lasso ›

Tails new CSV entries only and requires an existing helper profile plus a visible target window. It never deploys files to that application.

RTSS frame limiting ›

The global switch suspends or reapplies all selected profile limits without forgetting their configured FPS or limiter method.
